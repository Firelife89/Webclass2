Practical Project: Responsive Homepage Layout
Step 1: The HTML Structure
Create a semantic structure including a <nav>, <header> (hero section), <main> (with a features 
grid), and <footer>.
Step 2: The Flexbox Navigation
Use Flexbox to create a sticky navbar where the logo is on the left and links are spaced out on 
the right using justify-content: space-between;.
Step 3: The Grid Content
Create a "Features" section.
• Mobile: 1 column wide.
• Desktop: Use grid-template-columns: repeat(3, 1fr); to create a 3-column 
layout.
Step 4: Optimization
• Ensure images use max-width: 100%; to prevent overflowing on small screens.
• Adjust font sizes using rem units for better accessibility and scaling.
• Test using Browser Developer Tools in "Responsive Mode" to toggle between iPhone, 
iPad, and Desktop views.
